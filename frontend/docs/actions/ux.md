# UX — Filtres et actions

Principe directeur : **un seul endroit pour filtrer, un seul endroit pour trier.**

- **Un menu pour tous les filtres** : plutôt que d'ouvrir quatre menus différents, l'utilisateur ouvre un seul menu qui liste toutes les dimensions (unité, statut, contrat, etc.) avec leurs valeurs à cocher. Un compteur en haut indique combien de filtres sont actifs, et un lien "Réinitialiser tout" permet de repartir à zéro en un geste.
- **Tri à part** : le tri ne filtre pas, il ordonne. Il reste dans son propre menu à côté, avec une icône de flèche qui indique l'ordre croissant ou décroissant.
- **Retour immédiat** : pour les choix multiples ou uniques, le résultat s'affiche dès qu'on coche, sans bouton supplémentaire. Seule la période avec deux dates demande une validation explicite, pour éviter de relancer la recherche à chaque frappe.
- **Cohérence visuelle** : tous les modules (employés, congés, paie) parlent le même langage : même badge compteur, même case à cocher, même lien de réinitialisation discret en rouge.

Cette cohérence rend l'apprentissage plus rapide : une fois qu'on a compris comment filtrer les employés, on sait filtrer les congés.
