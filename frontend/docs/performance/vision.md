# Vision : Module Performance

> Évaluation continue des performances des employés, du pilotage des campagnes au développement individuel.

---

## Pourquoi ce système ?

- **Constat** : Pas de processus formalisé d'évaluation des performances. Les feedbacks sont informels, aucune traçabilité, pas de support pour les décisions de carrière (promotion, augmentation, PIP).
- **Opportunité** : Un module performance bien conçu permet d'aligner les objectifs individuels avec les objectifs de l'entreprise, de détecter les talents et de justifier les décisions RH.

## Objectifs

### Objectif principal
Permettre à une organisation de **gérer le cycle complet d'évaluation des performances** : de la définition des objectifs à la clôture, en passant par l'auto-évaluation, l'évaluation manager, le calibrage RH et le plan de développement.

### Objectifs secondaires
- Offrir une **vision consolidée** des performances par employé, équipe et département
- **Standardiser** le processus d'évaluation via des campagnes
- Fournir un **historique** complet des évaluations pour les décisions de carrière
- Calcul automatique des **scores pondérés** objectifs × compétences

### Non-objectifs
- Gérer la paie ou les augmentations (module payroll)
- Gérer les entretiens 1:1 informels (module calendar)
- Remplacer le module de gestion des talents (succession planning)

## Principes directeurs

1. **Simplicité** — Un cycle complet mais léger, sans surcharge administrative
2. **Équité** — Calibrage RH pour assurer la cohérence des notes entre équipes
3. **Traçabilité** — Chaque étape est horodatée, chaque modification est auditable
4. **Séparation des rôles** — Employé, manager, RH, direction ont des vues et actions différentes

## Parties prenantes

| Rôle | Attente principale |
|------|-------------------|
| **Employé** | Auto-évaluer ses objectifs, prendre connaissance de l'évaluation, signer |
| **Manager (N+1)** | Évaluer ses collaborateurs, définir les objectifs, rédiger le feedback |
| **RH** | Créer les campagnes, calibrer les notes, générer les rapports |
| **Direction** | Vue consolidée des performances par équipe/département |

## Périmètre

### Dans le périmètre
- Campagnes d'évaluation (création, pilotage, clôture)
- Objectifs SMART (définition, suivi, évaluation)
- Compétences (auto-évaluation et évaluation manager)
- Auto-évaluation par l'employé
- Évaluation par le manager
- Calibrage RH
- Plan de développement post-évaluation
- Scoring automatique (moyenne pondérée)
- Historique des évaluations

### Hors périmètre
- Feedback 360° (pairs, subordonnés) — version ultérieure
- Enquêtes d'engagement — module dédié
- Payroll / augmentation — module payroll
- Succession planning — version ultérieure
