# Module Évaluations de Performance

## C'est quoi le workflow ?

```
Création → Auto-évaluation (employé) + Évaluation (évaluateur) → Soumise → Approuvée
```

Les deux évaluent en parallèle. Quand les deux ont soumis, le score est calculé tout seul.

### Les statuts qu'on peut voir dans la liste

| Badge | Qu'est-ce que ça veut dire ? |
|---|---|
| **Auto-évaluation** | Personne n'a encore rien soumis |
| **En attente évaluateur** | L'employé a fini, reste à l'évaluateur |
| **En attente employé** | L'évaluateur a fini, reste à l'employé |
| **Soumise** | Tout le monde a soumis, score calculé |
| **Approuvée** | L'employé a validé les résultats |

---

## 👤 Tu es employé ? Voici comment ça se passe

### 1. On t'a créé une évaluation
Tu la vois dans ta liste avec le badge **"Auto-évaluation"**.

### 2. Tu notes tes objectifs et compétences
Clique sur le menu « ⋯ » → **"Noter mes objectifs"**.

Une feuille s'ouvre sur le côté. Tu notes chaque objectif (⭐ de 1 à 5), chaque compétence (niveau 1 à 5), tu peux ajouter un commentaire si tu veux. Tu cliques sur **"Enregistrer"**.

### 3. Tu soumets
Retourne dans le menu « ⋯ », maintenant tu as une nouvelle option : **"Soumettre à l'évaluateur"**.

Tu cliques, une pop-up te prévient : *"Une fois soumise, vous ne pourrez plus modifier votre auto-évaluation."*

Tu confirmes. Le badge devient **"En attente évaluateur"**.

### 4. Tu attends les résultats
Quand l'évaluateur a fini de son côté, le statut passe à **"Soumise"** et le score global est calculé automatiquement.

Tu peux ouvrir **"Voir les détails"** pour voir la comparaison côte à côte de vos deux évaluations.

### 5. Tu valides ou contestes
- Si tout va bien → menu « ⋯ » → **"Valider les résultats"** → badge **"Approuvée"**
- Si t'es pas d'accord → **"Contester"**

---

## 👤 Tu es évaluateur ? C'est pareil mais en parallèle

Le truc cool : tu n'as **pas besoin d'attendre** que l'employé ait fini pour commencer. Vous travaillez en même temps, chacun de votre côté, sans voir les notes de l'autre.

### 1. Tu ouvres l'évaluation
Menu « ⋯ » → **"Évaluer l'employé"**. C'est disponible dès le départ.

### 2. Tu notes
Tu vois les objectifs et compétences qui avaient été définis à la création. Tu mets tes propres notes, **tu ne vois pas ce que l'employé a mis**. Tu commentes si tu veux.

### 3. Tu soumets
Menu → **"Soumettre la notation"**. Une confirmation te demande si t'es sûr. Tu confirmes.

### 4. C'est fini
Quand l'employé a aussi soumis de son côté, le statut passe automatiquement à **"Soumise"** et le score global est calculé.

## 📊 Les scores

### Dans la liste (colonne Score)

Le score affiché change selon où on en est :

- **Auto-évaluation** 🟢 — si l'employé a noté
- **Note évaluateur** 🟣 — si l'évaluateur a noté
- **Score final** 🔵 — quand les deux ont soumis (calculé automatiquement)

### Dans le panneau de détail ("Voir les détails")

Deux cartes côte à côte avec les étoiles :

**Auto-évaluation** (vert) | **Note évaluateur** (violet)
---|---
⭐ 4.2 | ⭐ 3.7

Et tout en bas, un badge **Score final** (indigo) quand les deux ont soumis.

Les objectifs et les compétences s'affichent aussi en comparaison : une ligne par item, avec la note de chaque personne.

## ❓ Questions qu'on se pose souvent

**Est-ce que je peux modifier mes notes après avoir soumis ?**
Non, c'est bloqué. Si vraiment besoin, faut contacter le RH.

**L'évaluateur peut voir mes notes avant de soumettre ?**
Non, absolument pas. Chacun voit sa propre grille.

**Et si y'a pas d'évaluateur désigné ?**
Pas de souci. L'auto-évaluation est copiée automatiquement et le statut passe directement à soumis.

**Je peux supprimer une évaluation ?**
Oui, mais uniquement si personne n'a encore soumis. Menu → **"Supprimer"**.
